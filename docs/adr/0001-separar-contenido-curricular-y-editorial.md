# Separar contenido curricular y editorial

El contenido curricular del portfolio —perfil, experiencia, formación, proyectos y contacto— se mantendrá como datos estáticos tipados dentro de Astro; las publicaciones del blog seguirán en Sanity. Así el contenido de baja frecuencia conserva control de versiones y el contenido editorial mantiene edición independiente. El coste asumido es que cambiar el contenido curricular requiere un cambio y despliegue del sitio.
