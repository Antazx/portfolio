# Contrato de calidad pública

El sitio debe cumplir WCAG 2.2 AA, SEO técnico y descubribilidad para máquinas antes de publicarse. Esto incluye HTML semántico renderizado sin depender de JavaScript, metadatos por ruta, canonical y `hreflang`, sitemap, robots, datos estructurados JSON-LD y `llms.txt`; la publicación exige build, auditoría automatizada, navegación por teclado, revisión responsive e inspección del HTML generado. No se afirma que todos los buscadores o LLM indexen o comprendan el sitio.
