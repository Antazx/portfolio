# Mantener las traducciones de una publicación juntas

Cada publicación del blog se modelará como un documento Sanity con campos completos para castellano e inglés, un slug estable común y publicación conjunta; una ruta solo se generará cuando su traducción esté completa. Se elige para este blog personal porque evita relaciones y estados parciales innecesarios; si más adelante se necesita publicar idiomas independientemente, habrá que migrar a documentos localizados relacionados.
