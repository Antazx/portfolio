## 2. Data, source, and purposes

**Contact enquiries.** If the form is activated, it will process your name, email address, message, and selected language so the enquiry can be read and answered. In that case, the function would use the IP address to limit abuse, and Brevo is planned for sending the enquiry. If you email the confirmed contact address, the message and any personal data you include will be processed to reply; the mailbox provider will deliver it.

Enquiry data come from the message you send. If the form is activated, they will also come from the fields you complete and technical data the function uses for abuse controls. Enquiries will not be added to a marketing list.

**Newsletter.** If enabled, it would process your email address, selected language, signup and confirmation, and information needed to record and honour an unsubscribe. These data would be used to send portfolio updates in the selected language through the planned Brevo integration. No campaigns will be sent while the service remains disabled.

**Operation and security.** The site and hosting provider may generate technical data needed to deliver and protect the site, such as the date, requested path, request result, or IP address. Exact logs depend on the provider’s actual configuration and remain to be verified.

**Theme preference.** When you change the theme, the site stores your light or dark preference in the browser’s local storage. The code does not use it to identify you or build profiles. The value remains in that browser until changed or deleted. The lawyer will confirm what information or measures this storage requires.

No analytics or advertising tracking has been enabled, according to the owner.
